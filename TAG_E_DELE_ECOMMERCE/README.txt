TAG E DELE - MEN'S WEAR ECOMMERCE
=================================

One-folder PHP + MySQL ecommerce project for WAMP.

URL:
http://localhost/TAG_E_DELE_ECOMMERCE/

ADMIN:
http://localhost/TAG_E_DELE_ECOMMERCE/admin_login.php
Username: admin
Password: admin123

IMPORTANT:
1. Put this folder directly inside C:\wamp64\www\
2. Start Apache and MySQL.
3. Open the website URL. The project automatically creates the tag_e_dele_shop database and initializes tables on first run.
4. If you already imported the old database, the project automatically adds the new_arrival column.

MAIN FEATURES
- One-folder structure: no required subfolders.
- Add/edit/delete products from Admin.
- Change product name, category, SKU, price, old price, image, description, stock and active status.
- Mark products as New Arrivals.
- Product stock is shown as In Stock / Only X left / Out of Stock.
- Out-of-stock products cannot be added to cart.
- Cart remove really removes the selected product.
- Cart quantity cannot exceed available stock.
- Checkout checks stock again before placing an order.
- Successful orders automatically reduce stock.
- COD and Online UPI/Razorpay payment options are available in checkout. Razorpay requires your own API keys for real gateway payments.
- Admin order status management.
- Customer registration, login and order history.
- Responsive modern men's fashion design using the supplied shop logo and owner image.
